# 总目标

这是一个基于pixi7.js和rough.js的图形编辑器，核心功能如下：

1. 矢量图编辑功能：核心是svg的path。
2. 支持父子嵌套结构：使用pixi的节点树。
3. 支持对矢量图本身和pixi节点做动画。



# 数据结构

```js
class Node extends pixi.Graphics {
  _components = [];
}

class Component {
  node = null;
  update(dt) {}
}
```

1. Node是最基础的元素，负责和pixi交互 + 管理component，具体的功能都由component完成。
2. CompShape：绘制矢量图。verts是带圆角(r)的顶点，用rough.js生成手绘path后重放到pixi的Graphics。closed控制闭合/开放。
3. CompAnim：对Node或CompShape做动画。Track用路径寻址目标：
   - `transform/x`：Node自身属性(x/y/rotation...)
   - `style/fill`、`style/roughness`：CompShape样式，顶层(fill/stroke/width)与rough子对象(roughness/bowing/fillStyle...)自动区分
   - `vert/<id>/x`：某个顶点坐标
   - 前缀`#nodeId/`可跨节点寻址

# 样式模型(CompShape)

- 顶层：`fill` `stroke` `width` `closed`(可动画)
- `rough`：`{roughness, bowing, fillStyle, fillWeight, hachureGap}`(可动画)
- `seed`：每个图形固定，保证动画时手绘纹理稳定不抖
